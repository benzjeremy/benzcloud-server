Private Enterprise-Suite ohne Cloud-Zwang Private Enterprise Suite Without Cloud Lock-in

Die schlanke Open-Source-Alternative zu Nextcloud und Microsoft 365 komplett in reinem Go. Vollautomatisches Mesh-VPN ohne Router-Portfreigaben, eigener DNS-Server, AES-256-GCM Dateitresor und modulare Plugins für Web, Mail und Chat. The lightweight open-source alternative to Nextcloud and Microsoft 365 written entirely in pure Go. Autonomous Mesh-VPN without router port forwarding, embedded DNS server, AES-256-GCM file vault, and modular plugins for Web, Mail, and Chat.

Slack Nebula Mesh-VPN Slack Nebula Mesh VPN

Sichere Peer-to-Peer-Verschlüsselung via Noise-Protokoll. Funktioniert out-of-the-box hinter restriktiven Firewalls und NATs – ganz ohne Router-Portfreigaben. Built-in DNS daemon on port 53 (with automatic non-root fallback). Maps custom domains and subdomains like drive.domain or chat.domain locally.

Zero-Dummy-Security Zero-Dummy Security

Cryptographically uncompromising: AES-256-GCM authenticated encryption, PBKDF2 with 100,000 iterations, 32-byte CSPRNG tokens, and immutable VPN privileges.

Verschlüsselter Dateitresor Encrypted File Vault

Lokaler Cloud-Speicher mit Versionshistorie, Dateiuploads, Ordnerstrukturen und End-to-End-Verschlüsselung auf Blockebene. Private cloud storage featuring versioning, direct file uploads, folder hierarchies, and block-level cryptographic storage.

Plugin-Ökosystem Plugin Ecosystem

Modulare Erweiterbarkeit durch autonome Plugins: Webhosting (Astro/PHP), E-Mail (SMTP/IMAP) und Echtzeit-Chat mit automatischer Discovery via IPC. Modular architecture with autonomous plugins: Web hosting (Astro/PHP), Email (SMTP/IMAP), and real-time Chat with auto-discovery over local IPC.

Multi-Plattform Multi-Platform

Single-Binary-Ausführung auf Linux und Windows sowie eine schlanke native Android-Server-App (ohne Gradle- oder JAR-Ballast, direkt kompiliert). Single-binary deployments for Linux and Windows alongside a lightweight native Android server application without build bloat.

Mesh VPN Core

Slack Nebula Lighthouse- und Node-Konfiguratoren, CA-Zertifikatsausstellung und Peer-Erkennung ohne zentrale Server. Slack Nebula Lighthouse and node orchestrator, CA issuance, and peer discovery without centralized intermediaries.

RFC 1035 DNS Daemon

UDP/TCP Port 53 Handler für Mesh-Subdomains. Automatischer Fallback auf 5353 bei unprivilegierten Umgebungen. UDP/TCP Port 53 handler resolving mesh subdomains. Seamless 5353 fallback when running without root privileges.

Vhost Reverse Proxy

Dynamisches Routing eingehender HTTP-Anfragen basierend auf Host-Headern an die jeweiligen Subdienste und Plugins. Dynamic reverse proxy routing inbound HTTP requests by Host header to matching internal subsystems and plugins.

Plugin IPC Supervisor

Überwacht externe Plugin-Prozesse, fragt periodisch /health Endpunkte ab und aktualisiert DNS-Routing-Einträge. Monitors plugin child processes, periodically checks /health endpoints, and synchronizes DNS routing maps.
